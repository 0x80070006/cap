# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En résumé : soyez respectueux, accueillant et constructif ; aucun harcèlement, propos discriminatoire ou attaque personnelle n'est toléré. Les signalements se font de manière privée via les Security Advisories du dépôt ou auprès des mainteneurs, et sont traités avec confidentialité.
